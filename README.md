# jeremywhitlockk.github.io

Personal blog on iOS app security, mobile pentesting and AI-assisted vulnerability discovery.

Built with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) Jekyll theme and deployed with GitHub Pages.

## Writing a post

1. Drafts live in `_drafts/` and are not published.
2. To publish, move the file to `_posts/` and name it `YYYY-MM-DD-title.md`.
3. Push to `main`. GitHub Actions builds and deploys the site in about 2 minutes.
